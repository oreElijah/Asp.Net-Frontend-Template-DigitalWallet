# Test Failures due possible code bugs

## DigitalWalletTest.csproj - GetTransactionsByWalletIdAsync_WhenWalletHasSentAndReceivedTransactions_ReturnsCombinedOrderedList
- **Confidence**: High
- **Test File**: DigitalWallet/DigitalWalletTest/Repositories/TransactionRepositoryTests.cs
- **Bug Location**: DigitalWallet/DigitalWalletInfrastructure/Repositories/TransactionRepository.cs lines 137-140 (allTransactions.AddRange casts)

### Analysis
GetTransactionsByWalletIdAsync incorrectly casts entity collections (Wallet.SentTransactions and Wallet.ReceivedTransactions of type List<Transaction>) to IEnumerable<TransactionDto>, which causes InvalidCastException at runtime when entities are returned from EF. The code assumes DTO types where entity types exist and fails to map Transaction -> TransactionDto before combining and ordering.

### Suggested Fix
Map entity transactions to TransactionDto before combining. For example: var allTransactions = sentTransactions.Select(t => t.ToTransactionResponseDto()).Concat(receivedTransactions.Select(t => t.ToTransactionResponseDto())).OrderByDescending(t => t.CreatedAt).ToList(); Alternatively, change repository to project transactions from the database directly into TransactionDto using Select() or configure EF to return DTOs via a projection.
